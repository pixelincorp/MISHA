## 🚀 Инструкция по установке

1. Скачайте и установите **Melonloader** с [официального сайта](https://melonloader.co/download.html).

3. Запустите игру, чтобы Melonloader автоматически создал необходимые папки, после чего закройте игру.

4. Скачайте файл `MISHAAutoChest.dll` из репозитория и переместите его в папку:  
   `.\steamapps\common\MISHA\Mods\`

5. Запустите игру. Мод подгрузится автоматически.

## ⚙️ Полезные настройки

### Как убрать консоль Melonloader?
Если вы хотите скрыть окно консоли при запуске, выполните следующие действия:
1. Перейдите в папку `.\steamapps\common\MISHA\UserData\`.
2. Откройте файл `Loader.cfg` через любой текстовый редактор.
3. Найдите параметр `hide_console` и установите его значение на `true`:
   ```cfg
   hide_console = true
